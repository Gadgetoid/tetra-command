# Third party licences

The fonts in `py/fonts/` are distributed with the app, so their licenses are
reproduced here.

| File | Licence |
|------|---------|
| `Lexend[wght].ttf`, `lexend-regular.af` | [OFL-Lexend.txt](OFL-Lexend.txt) |
| `DSEG7Classic-Bold.ttf` | [OFL-DSEG.txt](OFL-DSEG.txt) |
| `MaterialSymbolsOutlined.ttf` | [Apache-2.0-MaterialSymbols.txt](Apache-2.0-MaterialSymbols.txt) |

`lexend-regular.af` is Lexend packed into the alright-fonts format, so it
carries Lexend's licence.

`themes.toml` and `py/derive.py` are vendored from
[statsbadge](https://github.com/pimoroni/statsbadge), same MIT licence as this.
